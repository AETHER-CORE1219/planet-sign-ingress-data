Saturn sign ingresses and Saturn returns (tropical, UTC)

A Saturn return is the time when transiting Saturn comes back to the geocentric ecliptic longitude it held at birth. Saturn’s sidereal orbital period is about 29.5 years, so the first return falls around age 29–30 and the second around age 58–60. Because the exact dates depend on the natal degree (and can include more than one pass if Saturn is retrograde), use the calculator for a birth date. The table below is the underlying tropical sign-ingress series from saturn-ingresses-1935-2080.csv (NASA JPL Horizons, UTC to the minute), which shows which tropical sign Saturn occupied in each year.
